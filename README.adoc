= Claude Clamp

A Docker container for running Claude Code with basic isolation.

== What It Does

Runs Claude Code in a container with:

* *Folder isolation* - Only mounted workspace is accessible
* *Network isolation* - Outbound traffic restricted to whitelisted domains (Anthropic API, GitHub, npm, Maven/Gradle)
* *Non-root user* - Claude runs as unprivileged user inside container

Check the link:Customization.adoc[] to see what you can customize.

== Limitations

This provides a *bare minimum* of isolation. Data exfiltration is still possible through allowed domains. This is not a security boundary, just a speed bump.

== Usage

[source,bash]
----
./clamp-claude.sh [options] <folder>
# or
./clamp-pi.sh [options] <folder>
----

Options:

* `-h, --help` - Show help message
* `--rebuild` - Force rebuild of the Docker image
* `--no-cache` - Rebuild without Docker layer cache
* `--per-project-auth` - Use separate credentials for this project
* `--no-firewall` - Disable the network firewall (allow all outbound traffic)
* `--shell` - Drop to shell instead of launching Claude (for debugging)

Environment variables:

* `CLAUDE_CLAMP_ADD_WORKFLOWS` - Set to `true` to copy bundled workflows into the container

*Example* to start in the current folder:

[source,bash]
----
./clamp-claude.sh .
# or
./clamp-pi.sh .
----

=== Global Installation

To call `claude-clamp` from anywhere, create a symlink, preferable in your local bin:

==== Create local bin (only if not exists)

Create the folder:

[source,bash]
----
mkdir -p ~/.local/bin
----

Ensure `~/.local/bin` is in your PATH.

For bash/zsh (add to `~/.bashrc` or `~/.zshrc`):

[source,bash]
----
export PATH="$HOME/.local/bin:$PATH"
----

For fish (run once):

[source,fish]
----
fish_add_path ~/.local/bin
----

==== Create symlink

Create symlink (in local bin):

[source,bash]
----
ln -s /path/to/repository/clamp-claude.sh ~/.local/bin/claude-clamp
----

Then run from anywhere:

[source,bash]
----
claude-clamp /path/to/project
----

== Requirements

== Dockerfiles and Images

The repository uses split Dockerfiles with a shared base:

* `clamp-base.Dockerfile` -> image `clamp-base`
* `clamp-claude.Dockerfile` -> image `clamp-claude`
* `clamp-opencode.Dockerfile` -> image `clamp-opencode`
* `clamp-pi.Dockerfile` -> image `clamp-pi`

Build manually:

[source,bash]
----
docker build -f clamp-base.Dockerfile -t clamp-base .
docker build -f clamp-claude.Dockerfile -t clamp-claude .
docker build -f clamp-opencode.Dockerfile -t clamp-opencode .
docker build -f clamp-pi.Dockerfile -t clamp-pi .
----

The wrapper scripts (`clamp-claude.sh`, `clamp-open-code.sh`, `clamp-pi.sh`) build these images automatically when needed.

== Workflows

The container includes bundled workflows but they are not copied by default. To enable them, set `CLAUDE_CLAMP_ADD_WORKFLOWS=true`.

=== Enabling Workflows Permanently

For bash (add to `~/.bashrc`):

[source,bash]
----
export CLAUDE_CLAMP_ADD_WORKFLOWS=true
----

For zsh (add to `~/.zshrc`):

[source,bash]
----
export CLAUDE_CLAMP_ADD_WORKFLOWS=true
----

For fish (add to `~/.config/fish/config.fish`):

[source,fish]
----
set -gx CLAUDE_CLAMP_ADD_WORKFLOWS true
----

After adding, reload your shell or run `source` on the config file.

== Network Isolation

=== Whitelisted Domains

The link:init-firewall.sh[] script sets the allowed domains. See link:claude/hooks/allowed-domains.txt[] for the full list. Includes:

* Anthropic API
* GitHub
* npm registry
* Maven/Gradle repositories
* JetBrains (Kotlin)
